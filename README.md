# Твой личный астролог — Telegram-бот

AI-бот для раскладов таро, гороскопов и нумерологии с подпиской в Telegram Stars.
Полное техническое задание — в [docs/TZ.md](docs/TZ.md).

## Что уже готово (Этап 1 — каркас)

- Онбординг `/start`: приветствие с дисклеймером → выбор языка (RU/EN) → имя → дата рождения →
  время и город рождения (можно пропустить) → знак зодиака и число жизненного пути.
- Deep-link: `/start ref_<telegram_id>` (реферал) и `/start src_<код>` (источник трафика).
- Главное меню со всеми разделами (разделы следующих этапов пока отвечают «скоро»).
- Профиль `/profile` с редактированием полей, временем Карты дня и включением рассылки.
- `/language` — смена языка, `/delete_me` — удаление всех данных пользователя.
- PostgreSQL со всеми таблицами из ТЗ, миграции Alembic, Redis для состояний диалога.
- Тексты в `app/locales/ru` и `app/locales/en` (формат Fluent).

## Запуск

Нужен только Docker.

1. Создайте бота у [@BotFather](https://t.me/BotFather) и получите токен.
2. Скопируйте настройки и впишите токен:
   ```bash
   cp .env.example .env
   # откройте .env и замените BOT_TOKEN и POSTGRES_PASSWORD
   ```
3. Запустите:
   ```bash
   docker compose up -d --build
   ```
4. Напишите боту `/start`.

Логи: `docker compose logs -f bot`. Остановка: `docker compose down`.

При старте бот сам применяет миграции и выставляет имя «Твой личный астролог»,
описание и список команд (имя меняется в `.env` → `BOT_NAME`).

### Режим webhook (для сервера)

По умолчанию бот работает в режиме `polling` — ему не нужен домен. На сервере с HTTPS можно
переключиться на webhook: в `.env` укажите `RUN_MODE=webhook`, `WEBHOOK_BASE_URL=https://ваш-домен`
и случайную строку в `WEBHOOK_SECRET`. Бот слушает порт 8080 на `127.0.0.1` — проксируйте на него
HTTPS через nginx или Caddy. Подробная инструкция для VPS появится на Этапе 7.

## Разработка

```bash
python3.12 -m venv .venv && . .venv/bin/activate
pip install -r requirements-dev.txt
pytest
```

Тесты по умолчанию идут на SQLite. Чтобы прогнать их на PostgreSQL:
`TEST_DATABASE_URL=postgresql+asyncpg://user:pass@localhost:5432/test_db pytest`.

Новая миграция после изменения моделей: `alembic revision --autogenerate -m "описание"`.

## Структура

```
app/
  bot.py          точка входа (polling / webhook)
  config.py       настройки из .env
  handlers/       start (онбординг), menu, profile, account
  services/       бизнес-логика: astrology, numerology, profile_input, users
  db/             модели, репозиторий, миграции
  locales/        тексты RU / EN
  keyboards.py    inline-клавиатуры
  middlewares.py  сессия БД, пользователь и переводчик для каждого апдейта
tests/            unit-тесты и сквозные тесты диалога
```

## Расчёты

- **Знак зодиака** — по стандартной таблице дат тропического зодиака.
  На стыке знаков граница может отличаться на ±1 день; точный расчёт по эфемеридам — позже, если понадобится.
- **Число жизненного пути** — день, месяц и год сводятся к одной цифре по отдельности, затем суммируются.
  Мастер-числа 11, 22 и 33 сохраняются.

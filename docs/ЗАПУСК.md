# Как запустить бота: пошаговая инструкция

Инструкция для тех, кто никогда этим не занимался. Сначала бот запускается на вашем
компьютере — так проще всего проверить, что всё работает. Пока компьютер включён, бот отвечает;
выключили компьютер — бот замолчал. Как перенести бота на сервер, чтобы он работал круглосуточно,
будет отдельная инструкция (Этап 7).

Понадобится около 30–40 минут. Примеры даны для Windows, отличия для Mac — в конце.

---

## Шаг 1. Создать бота в Telegram и получить токен

Токен — это «пароль» бота. С ним программа управляет ботом.

1. Откройте Telegram и найдите **@BotFather** (с синей галочкой).
2. Нажмите «Запустить» (или напишите `/start`), затем отправьте `/newbot`.
3. BotFather спросит имя — отправьте:
   `Твой личный астролог | Таро и гороскоп`
4. Затем спросит ник (username) — отправьте:
   `TaroAstrologiaGoroskopBot`
   Ник обязательно заканчивается на `bot`. Если он занят, BotFather скажет об этом —
   попробуйте `TaroAstrologiyaGoroskopBot` или `TvoyAstrologTaroBot`.
5. BotFather пришлёт сообщение с длинной строкой вида
   `7123456789:AAHk3x...` — это и есть **токен**. Скопируйте его и сохраните.

> ⚠️ Никому не показывайте токен. Если он случайно попал к кому-то — в @BotFather отправьте
> `/revoke`, выберите бота и получите новый.

Описание бота и список команд программа выставит сама при первом запуске.

---

## Шаг 2. Установить Docker Desktop

Docker — программа, которая запускает бота вместе с базой данных одной командой.
Ничего, кроме неё, ставить не нужно.

1. Откройте https://www.docker.com/products/docker-desktop/ и нажмите **Download for Windows**.
   (Если сайт не открывается — включите VPN.)
2. Запустите скачанный файл. На экране **Configuration** выберите
   **All-users installation (Requires password)**, галочку **Use WSL 2 instead of Hyper-V** оставьте,
   **Allow Windows Containers** не отмечайте, нажмите **OK** и разрешите изменения (может спросить пароль Windows).
   Вариант «Per-user» не подходит, если в Windows выключен компонент «Платформа виртуальной машины» —
   установщик остановится с ошибкой *Virtual Machine Platform*.
   Если установка всё равно не идёт: откройте **PowerShell от имени администратора**
   (Пуск → PowerShell → правой кнопкой → «Запуск от имени администратора»), выполните `wsl --install`,
   перезагрузите компьютер и запустите установщик снова.
3. Перезагрузите компьютер, когда попросит.
4. Откройте **Docker Desktop** (появится значок кита 🐳 в углу экрана у часов).
   Примите соглашение, регистрацию можно пропустить (**Skip**).
5. Подождите, пока внизу окна Docker Desktop появится зелёная надпись **Engine running**.

Docker Desktop должен быть запущен каждый раз, когда вы хотите, чтобы бот работал.

## Шаг 3. Скачать код бота

1. Откройте https://github.com/Sw1Sgood/TelegramBot (войдите в свой аккаунт GitHub).
2. Нажмите зелёную кнопку **Code** → **Download ZIP**.
3. Распакуйте архив (правой кнопкой → «Извлечь всё») в удобное место, например в `C:\bot`.
   Внутри появится папка `TelegramBot-main` — дальше работаем в ней.

---

## Шаг 4. Вписать токен в настройки

1. Сначала включите показ расширений файлов, иначе Windows спрячет часть имени:
   в Проводнике меню **Вид** → **Показать** → поставьте галочку **Расширения имён файлов**.
2. В папке `TelegramBot-main` найдите файл `.env.example`.
   Скопируйте его (Ctrl+C, Ctrl+V) и переименуйте копию в **`.env`** — ровно так,
   с точкой в начале и без `.example` и `.txt` в конце. На вопрос Windows о смене расширения ответьте «Да».
3. Откройте `.env` правой кнопкой → **Открыть с помощью** → **Блокнот**.
4. Замените две строки:
   ```
   BOT_TOKEN=сюда_вставьте_токен_из_шага_1
   POSTGRES_PASSWORD=придумайте_любой_пароль
   ```
   Пример:
   ```
   BOT_TOKEN=7123456789:AAHk3xYourTokenHere
   POSTGRES_PASSWORD=Luna2026star
   ```
   Без пробелов вокруг `=` и без кавычек. Остальное не трогайте.
5. Сохраните (Ctrl+S) и закройте Блокнот.

---

## Шаг 5. Запустить бота

1. Откройте папку `TelegramBot-main` в Проводнике.
2. Кликните в адресную строку сверху (где написан путь к папке), сотрите путь,
   напишите `cmd` и нажмите **Enter**. Откроется чёрное окно — командная строка, уже в нужной папке.
3. Вставьте эту команду и нажмите **Enter**:
   ```
   docker compose up -d --build
   ```
4. Первый запуск занимает 3–10 минут: Docker скачивает всё нужное. Побегут строчки — это нормально.
   В конце должны появиться строки со словами **Started** или **Running**.

Готово! Откройте в Telegram `@TaroAstrologiaGoroskopBot` (или ваш ник) и нажмите **Запустить**.

## Как управлять ботом

Все команды вводятся в командной строке, открытой в папке бота (как в шаге 5).

| Что нужно | Команда |
| --- | --- |
| Остановить бота | `docker compose stop` |
| Снова запустить | `docker compose up -d` |
| Посмотреть, что происходит (логи) | `docker compose logs -f bot` — выход: Ctrl+C |
| Проверить, что всё работает | `docker compose ps` — у всех трёх строк должно быть `Up` |

Данные пользователей хранятся внутри Docker и не пропадают при остановке и перезапуске.

**После перезагрузки компьютера** бот запустится сам, как только откроется Docker Desktop.

### Как обновить бота, когда выйдет новая версия

1. Скачайте ZIP заново (шаг 3) и распакуйте.
2. Перенесите в новую папку свой файл `.env` из старой.
3. В новой папке выполните `docker compose up -d --build`.

Данные пользователей сохранятся.

## Если что-то не работает

Сначала посмотрите логи: `docker compose logs --tail 50 bot`. Частые ситуации:

| Что видите | Что делать |
| --- | --- |
| `docker` не является внутренней или внешней командой / `cannot connect to the Docker daemon` | Docker Desktop не запущен. Откройте его и дождитесь **Engine running**. |
| В логах `Unauthorized` | Неверный токен. Проверьте строку `BOT_TOKEN` в `.env`, затем `docker compose up -d`. |
| В логах `Conflict: terminated by other getUpdates` | Бот запущен в двух местах с одним токеном. Оставьте только один. |
| `env file ... .env not found` | Файл называется не `.env` (часто получается `.env.txt`). Переименуйте, см. шаг 4. |
| Скачивание обрывается, `TLS handshake timeout`, `429` | Проблема сети. Подождите пару минут и повторите команду; при необходимости включите VPN. |
| Бот молчит, ошибок нет | Убедитесь, что пишете тому боту, чей токен в `.env`, и что `docker compose ps` показывает `Up`. |

Если не получается — скопируйте последние строки логов и пришлите их мне.

## Для Mac

Всё так же, кроме:

- Шаг 2: на сайте Docker выберите **Download for Mac** — Apple Silicon (M1–M4) или Intel
  (посмотреть: меню  → «Об этом Mac»). Перетащите Docker в «Программы» и запустите.
- Шаг 4: файлы с точкой в начале скрыты — в Finder нажмите **Cmd + Shift + .** чтобы их показать.
  Редактировать `.env` можно в TextEdit (меню Формат → «Сделать простым текстом»).
- Шаг 5: откройте **Терминал**, напишите `cd ` (с пробелом), перетащите папку `TelegramBot-main`
  в окно Терминала, нажмите Enter — и дальше те же команды.
